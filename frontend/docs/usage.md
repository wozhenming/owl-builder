# CostOntology Editor 使用文档

公路工程造价本体可视化编辑器——无需编写 XML，用图形化方式创建、编辑和查看 OWL 本体。

## 一、快速开始

### 1. 启动应用

- **Windows**：双击项目根目录的 `start-dev.bat`，浏览器打开 http://localhost:5173
- **手动启动**：
  ```bash
  cd backend && .venv\Scripts\python -m uvicorn app.main:app --port 8000   # 后端
  cd frontend && npm install && npm run dev                                # 前端
  ```

### 2. 创建第一个项目

1. 首页点击 **「新建项目」**，填写项目名称（如「某高速公路造价本体」）
2. 点击 **「创建并打开」** 进入编辑器
3. 想快速体验？首页点击 **「使用示例模板」**，内置一个公路造价本体示例（建设项目 → 单位工程 → 分部工程 → 分项工程 → 清单项/定额子目）

### 3. 界面总览

```
┌──────────────────────────────────────────────────────────────┐
│ 工具栏：项目列表 | 名称 | 撤销 重做 保存 自动排版 | 添加类 添加属性 | 导入 导出 | 源码 │
├──────────────────────────────────────────┬───────────────────┤
│                                          │ 右侧面板          │
│              画布（图形视图）              │  详情 / 添加 / 源码 │
│    图例（左上）   统计（右上）   小地图（右下） │                   │
└──────────────────────────────────────────┴───────────────────┘
```

- **画布**：拖拽空白处平移、滚轮缩放、左下角控制按钮缩放/居中
- **图例**（左上）：解释各类线条与层级颜色，鼠标悬浮可看说明
- **右侧面板**：「详情」编辑选中实体、「添加」快速建模、「源码」预览 OWL XML

## 二、建模教程

### 1. 添加类（Class）

点击工具栏 **「添加类」** 或右侧面板 **「添加」→「类」**：

| 字段 | 说明 |
| --- | --- |
| 类名（IRI 本地名） | 类的唯一标识，将拼入完整 IRI。如 `分项工程` → `http://…/分项工程` |
| 中文显示名 | 画布上显示的名称（写入 `rdfs:label`） |
| 注释 | 类的说明（写入 `rdfs:comment`） |

> 类名不可重复，不可包含空格。

### 2. 建立子类关系（继承）

在画布上，从**子类**的右侧圆点拖拽连线到**父类**，松开后选择「子类关系」即可（或在添加属性对话框中完成）。子类自动继承父类的一切属性。

### 3. 添加数据类型（Datatype）

右侧面板 **「添加」→「数据类型」**，选择标准类型（`xsd:string`、`xsd:decimal` 等）。数据类型节点作为**数据属性的值域**。

### 4. 添加属性（Property）

属性有三种类型，表达不同的语义：

| 类型 | 含义 | 示例 |
| --- | --- | --- |
| 对象属性 | 连接**两个类** | 「清单项」→「定额子目」：套用定额 |
| 数据属性 | 连接**类与数据类型** | 「清单项」→`xsd:decimal`：工程量 |
| 注解属性 | 类的附加说明（虚线边） | 「建设项目」→`xsd:string`：审批文号 |

**推荐方式（拖拽连线）**：从类的右侧圆点拖到目标节点（类或数据类型），松开后自动打开属性对话框，**起点与终点已预填**，只需填写属性名。

**表单方式**：工具栏 **「添加属性」**，手动选择定义域 Domain（起点）与值域 Range（终点）。

> 函数型属性（FunctionalProperty）：勾选后表示每个个体至多有一个该属性的值，如「单位造价」。

### 5. 编辑与删除

- **编辑**：点击画布上的类或关系边，右侧「详情」面板修改名称、显示名、注释、定义域/值域等
- **删除**：选中后按 `Delete` / `Backspace` 键；删除类会级联删除其全部关系边
- 所有操作均可 **Ctrl+Z 撤销**

## 三、自动排版

画布节点杂乱时，点击工具栏 **「自动排版」**：

- 按**类层级**自动分层：根类在最上，子类逐层向下
- 每个层级有清晰间距，类节点头部**颜色随层级递变**（根类最深，越深越浅）
- 数据类型自动归位（单个的放在类右侧，多个的归入右侧数据列）
- 排版后自动缩放至全图；排版结果可**撤销**，也可随项目**保存**

## 四、多项目管理与保存

- 首页项目列表可创建/打开/删除多个项目
- 工具栏 **「保存」**：已连接后端时保存到服务器（SQLite），未连接时保存到浏览器本地（自动降级，界面显示「本地模式」）
- 右上角 **「已连接 / 本地模式」** 显示当前存储方式
- **布局（节点位置）随项目一起保存**，重新打开后位置不变

## 五、导入与导出

| 操作 | 说明 |
| --- | --- |
| 导入 `.owl` | 加载标准 OWL RDF/XML 文件（兼容 CURIE 前缀、中文编码 GB18030） |
| 导入 `.json` | 恢复本编辑器的 JSON 备份 |
| 导出 OWL | 生成**标准 OWL RDF/XML** 文件下载 |
| 源码视图 | 右侧「源码」标签实时预览 XML，可复制/下载 |

> 导入会**替换当前内容**；存在未保存修改时会先询问确认。

支持导出/解析的 OWL 结构：`owl:Class`、`rdfs:subClassOf`、`rdfs:label`、`rdfs:comment`、`owl:ObjectProperty`、`owl:DatatypeProperty`、`owl:AnnotationProperty`、`owl:FunctionalProperty`、`owl:versionInfo`。

## 六、快捷键

| 按键 | 功能 |
| --- | --- |
| `Ctrl+Z` | 撤销（内容与布局均可撤销） |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Delete` / `Backspace` | 删除选中的类或关系边 |
| `Esc` | 关闭对话框 / 取消选中 |
| 滚轮 | 缩放画布 |

## 七、名词解释

| 名词 | 说明 |
| --- | --- |
| 本体（Ontology） | 对领域概念及其关系的正式描述。本工具编辑的是 OWL 本体 |
| OWL | W3C 本体描述语言标准，本工具读写 OWL 2 的 RDF/XML 语法 |
| IRI | 实体的全局唯一标识（类似网址），如 `http://example.org/cost-ontology#分项工程` |
| 命名空间 | 一类实体 IRI 的公共前缀，在新建项目时指定 |
| Class（类） | 概念本身，如「清单项」「定额子目」 |
| rdfs:subClassOf | 子类关系：子类继承父类的属性，如「分项工程」是「分部工程」的子类 |
| Domain（定义域） | 属性的起点（主体），如「工程量」的定义域是「清单项」 |
| Range（值域） | 属性的终点（取值），对象属性指向类、数据属性指向数据类型 |
| FunctionalProperty | 函数型属性：每个个体至多一个取值 |
| rdfs:label / rdfs:comment | OWL 中的中文名称 / 注释字段 |
| XSD 数据类型 | W3C 标准数据类型（string、integer、decimal、boolean、date 等） |
| RDF/XML | OWL 本体的一种标准文件格式（.owl 文件） |

## 八、常见问题

**问：保存时提示「尚未关联项目」？**
答：请从首页项目列表进入项目，而不是直接使用导入后的临时会话。

**问：导入的 .owl 有部分内容没显示？**
答：缺少 domain/range 的属性或匿名限制（owl:Restriction）会被跳过并在提示中说明，这类结构暂不支持。

**问：多个父类（多继承）如何表现？**
答：类可以有多个父类边；自动排版时取第一条父类边作为主层级，其他父类关系仍正常显示。

**问：为什么某些类排在顶层？**
答：没有父类（未连子类关系）的类都是根类。若想让它成为子类，用「子类关系」连到目标父类。

**问：数据放在哪里？**
答：后端模式下保存在服务器 SQLite 数据库；本地模式下保存在浏览器 localStorage，清除浏览器数据会丢失，建议定期导出 .owl 备份。
