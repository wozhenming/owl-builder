# 管理后台（仅管理员可见）

以下章节为管理员专属文档。管理后台入口：登录管理员账号后，首页右上角「**管理后台**」按钮。

## 一、用户管理

管理后台 → **用户管理** Tab，可查看全部用户（用户名 / 角色 / 项目数 / 注册时间），并执行：

| 操作 | 说明 |
| --- | --- |
| 重置密码 | 为用户设置新密码，其现有登录会话将全部失效 |
| 删除用户 | 选择该用户项目的处理方式后删除账号（见下） |

### 删除用户时的项目处理方式

| 方式 | 效果 |
| --- | --- |
| 转为公开项目 | 项目与文件夹转为公共数据，所有登录用户可见、可编辑 |
| 转给指定用户 | 项目与文件夹移交给所选用户（需先选择接收者） |
| 连同项目删除 | 项目及全部本体数据被**永久删除**，不可恢复 |

> 注意事项：
> - 不能删除当前登录的账号
> - 至少需要保留一名管理员（最后一个管理员不可删除）
> - 被删除用户的模板下发记录会一并清除

## 二、模板管理

管理员可创建模板并下发给指定用户，普通用户在选择「使用示例模板」时即可看到。

### 创建 / 编辑模板

1. 管理后台 → **模板管理** Tab → 「新建模板」
2. 填写：模板名称（必填）、领域标签、图标（emoji）、描述
3. **上传模板内容**：支持 `.owl`（标准 OWL RDF/XML）与 `.json`（编辑器备份）文件，系统自动解析为本体
4. 选择可见范围：
   - **所有人可见**：所有用户都能看到该模板
   - **仅下发给指定用户**：勾选需要下发的用户，只有这些用户能看到
5. 保存后模板立即生效

### 编辑与删除

- 模板卡片悬停可「编辑」（修改信息或重新上传内容覆盖）或「删除」
- 删除模板不影响已从该模板创建的项目

### 模板内容建议

- 上传前先在编辑器中建好本体并导出 `.owl`（或保存 JSON 备份）
- 模板可复用：同一份 `.owl` 可创建多个不同名称/领域/下发的模板

## 三、权限与数据模型

| 角色 | 可见数据 | 能力 |
| --- | --- | --- |
| 匿名（未登录） | 仅公共数据（无归属的项目/文件夹） | 完整编辑功能；匿名创建的数据为公共数据 |
| 普通用户 | 公共数据 + 自己的项目/文件夹 | 完整编辑功能；管理员下发的模板可见 |
| 管理员 | 公共数据 + 自己的数据 + 管理后台 | 用户管理、模板创建下发 |

数据归属规则：

- 登录用户创建的项目/文件夹归属该用户，其他用户**不可见、不可修改**
- 公共数据（无归属）所有登录用户可见可编辑
- **第一个注册的用户自动成为管理员**，并接管此前匿名模式创建的全部数据
- 删除用户时按所选方式处理其数据（公开 / 转移 / 删除）

## 四、安全说明

- 密码经 pbkdf2 加盐哈希存储，不保存明文
- 登录令牌随机生成并存储于服务端，登出即失效；重置密码会使该用户全部令牌失效
- 管理接口均有管理员权限校验（非管理员访问返回 403）
